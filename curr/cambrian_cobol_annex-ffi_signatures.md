# Annex C: Runtime FFI Function Signatures (`cambrian_cobol_annex-ffi_signatures.md`)

* **Component Owner:** Cambrian Radiation Core Engineering
* **Target Compatibility:** GnuCOBOL 3.2 Generated C Intermediate Code (`cobc -C`)
* **Linkage Constraint:** Zero `-lcob` Dependency (Clean-Room Memory Mirroring)
* **Status:** Draft / Active / Normative

---

## 1. Overview & Architectural Bound

To satisfy the zero `-lcob` linkage constraint, the `cambrian-cobol` runtime core implements a clean-room replacement for the GnuCOBOL runtime library. Generated C code emitted by `cobc -C` relies on a standardized symbol surface for program initialization, data movement, decimal arithmetic, file input/output, sorting, parameter stacking, and string processing. 

All functions defined in this annex **MUST** be exposed via `#[no_mangle]` and `extern "C"` ABIs within the Rust runtime workspace, maintaining byte-level compatibility with pointer layouts specified in Annex B (`CobField`, `CobFieldAttr`, `CobFile`, `CobDecimal`).
